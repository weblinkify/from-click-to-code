# Lesson 3 · The UI: drawing before building 🎨

**UI** stands for **User Interface**: everything you can see and touch in an
app, like buttons, boxes, words and colours.

Before building, designers **sketch** the screens. It's much faster to rub out
a pencil line than to rewrite code! This kind of quick sketch is called a
**wireframe**.

It's like an architect drawing a house plan before anyone picks up a brick.

Arrows between screens show the **user flow**, the path people take:

```
  Welcome --click--> Log in --sign up / log in--> My todos --log out--> Log in
```

## Three languages, three jobs

Web pages are made from three languages working together. Think of a person:

| Language | Job | Like a person's… |
|----------|-----|------------------|
| **HTML** | What's on the page | Skeleton |
| **CSS** | How it looks | Clothes |
| **JavaScript** | What it does | Muscles |

## Building with Lego bricks: React components

Our app uses **React**, a popular library for building UIs. React lets us
write the HTML *and* the JavaScript for one piece of the screen together, in a
**component**: a reusable Lego brick for the screen.

```
  The "My todos" screen is built from bricks:

  ┌───────── app/(site)/my-todos/page.js ─────────┐
  │  ┌──────── AddTodoForm ────────┐              │
  │  │ [What to do?______] [Add]   │              │
  │  └─────────────────────────────┘              │
  │  ┌──── Message ────┐                          │
  │  │ Added! 🎉        │                          │
  │  └─────────────────┘                          │
  │  ┌──────── Filters ──────────┐                │
  │  │ [All] [To do] [Done]      │                │
  │  └───────────────────────────┘                │
  │  ┌──────── TodoItem ─────────────────────┐    │
  │  │ [✓] Feed the cat            [Delete]  │    │  one TodoItem
  │  └───────────────────────────────────────┘    │  per todo!
  │  ┌──────── TodoItem ─────────────────────┐    │
  │  │ [ ] Tidy my room            [Delete]  │    │
  │  └───────────────────────────────────────┘    │
  └───────────────────────────────────────────────┘
```

| Brick (component) | File |
|-------------------|------|
| The whole page | [`app/(site)/my-todos/page.js`](../app/%28site%29/my-todos/page.js) |
| The add box | [`components/AddTodoForm.js`](../components/AddTodoForm.js) |
| One todo line | [`components/TodoItem.js`](../components/TodoItem.js) |
| The filter buttons | [`components/Filters.js`](../components/Filters.js) |
| The look (CSS) | [`app/globals.css`](../app/globals.css) |

The HTML-looking code inside a component is called **JSX**. Anything in
`{curly braces}` is JavaScript, like `{todo.text}`.

## Good UI is kind UI

Some choices we made to be friendly to *everyone*:

- **Big buttons and text** (18px), easy to tap and read.
- **Labels on every box**, so screen readers (programs that read the page
  aloud for people who can't see it) know what each box is for.
- **Friendly messages**, like *"Added! 🎉"* or *"Please write something for
  your todo."*, never scary error codes.
- A **yellow banner** when the server can't be reached, instead of a blank page.
- It works on a **phone-sized screen** too (look for `@media` in `globals.css`).

## New words

- **UI**: User Interface, what you see and click.
- **Wireframe**: a simple sketch of a screen.
- **User flow**: the path someone takes through the screens.
- **HTML / CSS / JavaScript**: the skeleton, clothes and muscles of a web page.
- **React**: a library for building UIs out of components.
- **Component**: a reusable piece of the screen, like a Lego brick.
- **JSX**: the HTML-looking code inside a React component.
- **Accessibility**: making sure *everyone* can use the app.

## Questions

   <details><summary>Answer</summary>

2. Why sketch screens before writing code?
   <details><summary>Answer</summary>
   Sketches are quick to change. You can spot problems (like a missing
   "Log out" button) before spending hours building the wrong thing.
   </details>

## 🛠️ Mini challenge

Open http://localhost:3000/my-todos. Right-click a button and choose
**Inspect**. This opens the browser's **DevTools**, a toolbox built into every
browser. You'll see the HTML for that button. In the **Styles** panel on the
side, find `background` and click the colour square to change it. (Don't
worry, it only changes on your screen, and a refresh puts it back!)
