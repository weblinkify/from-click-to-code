# Lesson 1 · The idea 💡

Every app you've ever used, from games to video sites to the app your school
uses, started the same way: **somebody had a problem and an idea to fix it.**

Ours is simple:

> *"I keep forgetting the things I need to do. I wish I had a list that
> lived on the internet, so I could tick things off from any computer."*

That's it. That's the whole idea for **Kids Todo App**. In these lessons we'll
follow that idea all the way to a real, working app, and you can open every
file we talk about.

## Starting small is a superpower

It's tempting to dream big: *"It'll have games! And chat! And a robot pet!"*
Real builders do the opposite. They pick the **smallest version that's still
useful** and build that first. Software people call this an **MVP**, a
*Minimum Viable Product*: the simplest thing that actually works.

Think about building a treehouse. You don't start with the slide, the rope
ladder and the secret trapdoor. You start with **a floor that holds you up.**
Once that works, you add the fun bits.

```
   The dream treehouse            What we build first (MVP)

        /\    🚩                          ________
       /  \  ___                         |        |
      /____\|   |  <- slide              |  floor |
      | [] ||   |                        |________|
      |____||___|  <- trapdoor               ||
         ||   \\                             ||
         ||    \\  <- rope                   ||
```

Our MVP does five things:

1. **Sign up** (make an account)
2. **Log in**
3. **Add** a todo
4. **Tick it off** when it's done
5. **Delete** it

No colours to pick, no sharing, no reminders. Those could come later!

## New words

- **App** (short for *application*): a program that does a job for people.
- **Web app**: an app you use inside a web browser (like Chrome, Safari or
  Firefox) instead of installing it.
- **MVP**: the smallest version of an idea that's still useful.

## Questions

1. Why do builders start with the smallest useful version?
   <details><summary>Answer</summary>
   So they can finish something real quickly, check that people actually
   want it, and learn before spending time on extras. A floor you can stand
   on is better than half a castle.
   </details>

2. Name one feature that is **not** in our MVP.
   <details><summary>Answer</summary>
   Lots of good answers: reminders, sharing lists with friends, colours,
   due dates, pictures... They're all "maybe later" ideas.
   </details>

3. What problem does Kids Todo App solve?
   <details><summary>Answer</summary>
   Remembering things you need to do, and being able to tick them off from
   any computer.
   </details>
