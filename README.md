# Kids Todo App 📝

A small, **real** web app for learning how websites work — from an idea all the
way to a server in the cloud.

You can sign up, log in, add a todo, tick it off, and delete it. Every part of the
code is written to be *read*, with simple comments, so a grown-up and a kid can
explore it together.

> 🚧 This project is being built step by step. Each step is one Git commit, so the
> history itself tells the story. Full "how to run it" instructions arrive as the
> app grows.
